# 🛰️ ALLANAI.CrimeVision
**Author:** Mahira | ALLANAI Labs  
**Dataset Source:** [UK Police API](https://data.police.uk/api/)  
**Coverage:** Oct 2022 – Oct 2025  

ALLANAI.CrimeVision is an open-source project under **ALLANAI Labs** that collects, cleans, and analyzes UK crime data for research in AI, safety analytics, and smart-city insights.

### 📦 Current Release: Phase 1 (Oct–Dec 2022)
- Data for 5 major forces (London, Manchester, Birmingham, Leeds, Thames Valley)  
- 3 months of crime records (Oct–Dec 2022)  
- Fetched via official UK Police API  
- Includes merged CSV + EDA Notebook  

### 📂 Repository Structure
| Folder | Description |
|--------|--------------|
| `data_uk_2022_10–12/` | Raw monthly data per police force |
| `merged/` | Clean combined dataset ready for Kaggle |
| `notebooks/` | Jupyter notebooks for analysis |
| `reports/` | Documentation and metadata |
